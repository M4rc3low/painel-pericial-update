# Status do repositório

## Situação atual

- Repositório preservado como histórico.
- Não contém código executável além da documentação.
- Não deve ser usado como referência principal do portfólio.

## Projeto relacionado

A evolução do conceito de painel pericial está representada no projeto **PeritoLex**, que concentra a implementação atual voltada à organização de processos, prazos, documentos e alertas.

Projeto: https://github.com/M4rc3low/peritolex-app

## Observação

Este arquivo existe para deixar claro o propósito do repositório e evitar que uma pessoa que chegue pelo GitHub interprete a ausência de código como um projeto quebrado ou incompleto sem contexto.
